### 作品

**實驗室計畫**
- [Hitter-Skeleton](https://github.com/partner0487/Hitter-Skeleton)：棒球打擊動作分析。用兩台相機從正面和側面同步錄影，YOLO 抓打者和球棒、ViTPose 抓骨架，分析揮棒動作和 3D 姿態。這是從學長姐那邊接手的計畫，我負責繼續開發和優化。

**碩士課程**
- [RL_Platform_Game](https://github.com/partner0487/RL_Platform_Game)：自己寫的 PyGame 平台跳躍遊戲，再訓練 agent 去玩。一個讀遊戲數值的 PPO、一個只看畫面的 CNN，比較兩者的表現。

**個人專案**
- [hoyoCalendar](https://github.com/partner0487/hoyoCalendar)：自動抓原神、星鐵、鳴潮等遊戲官網公告，整理成日曆，可以一鍵同步到 Google 日曆。([Demo](https://hoyo-calendar.vercel.app))
- [hoyoTTS](https://github.com/partner0487/hoyoTTS)：用 OCR 讀遊戲劇情的文字和角色名稱，再用 AI 配音念出來。
- [TaskSystem](https://github.com/partner0487/TaskSystem)：Android 待辦 App，沒做完的任務會一直掛在通知欄，拉下來就能打勾。
- [Auto_Doctor_Checker](https://github.com/partner0487/Auto_Doctor_Checker)：盯著線上候診系統的看診進度，快輪到自己時提醒。

**大學課程**
